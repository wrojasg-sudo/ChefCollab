## 3. Descripción del proyecto

ChefCollab es una plataforma web orientada al descubrimiento, la organización y el intercambio de recetas culinarias. Su propósito es facilitar la búsqueda de recetas según los ingredientes disponibles, el presupuesto, las preferencias alimentarias y el nivel de dificultad.

La plataforma también busca fomentar la colaboración entre usuarios mediante la creación de recetas personalizadas, las valoraciones, los comentarios y el seguimiento de chefs y creadores de contenido culinario.

## 4. Alcance del proyecto

El proyecto contempla el diseño y desarrollo de una interfaz web utilizando HTML, CSS y JavaScript.

Entre las funcionalidades propuestas se encuentran:

- Búsqueda y filtrado de recetas.
- Visualización de ingredientes, costos y pasos de preparación.
- Guardado de recetas favoritas.
- Creación de versiones personalizadas de recetas.
- Planificación semanal de comidas y elaboración de listas de compras.
- Calificación y comentarios de recetas.
- Gestión de categorías y moderación de contenido.

Las funcionalidades se implementarán de acuerdo con los requerimientos y las prioridades definidas por el equipo.

## 5. Estrategia de ramas y commits

Se utilizará Git y GitHub para mantener el control de versiones y facilitar la colaboración.

- `main`: contiene la versión estable del proyecto.
- `develop`: integra los avances del equipo antes de incorporarlos a la versión estable.
- `feature/nombre-funcionalidad`: se utilizará para desarrollar funcionalidades específicas.

Los commits tendrán mensajes claros que describan los cambios realizados, por ejemplo:

- `docs: agregar README principal`
- `docs: incorporar wireframes en PDF`
- `feat: crear estructura inicial de la página`
- `style: ajustar estilos de navegación`

Los cambios se revisarán e integrarán en las ramas correspondientes antes de actualizar la versión estable.
